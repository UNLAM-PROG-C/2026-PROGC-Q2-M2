# Asset sources

The game uses a selected subset of **Space Shooter Remastered** by Kenney:

- Source: https://kenney.nl/assets/space-shooter-remastered
- License: Creative Commons CC0 1.0 Universal
- Local license copy: `KenneySpaceShooter/LICENSE.txt`

Files were renamed by gameplay purpose to keep resource references stable. No
networking, simulation, or collision behavior depends on these visual assets.
